# Gym Companion

A phone-first gym companion built around technique. Open a workout and follow
it one exercise at a time: a looping 3D demo with the working muscles lit up,
form cues, the common mistakes to avoid, and one big **Done** button to move on.
A library of 32 exercises, grouped by muscle, lets you study any movement or
put together a custom workout. Installable as a PWA and works offline.

## Features

- Workouts: Full Body, Pull, Workout 3 and your own; a plan view before you start
- One exercise at a time: 3D demo (drag to turn, pinch to zoom), Form / Avoid / Works notes
- Supersets flagged ("No rest. Go straight into…"); jump to any exercise from the list
- Library: 32 exercises in 9 groups (chest, back, shoulders, biceps, triceps, core,
  quads, glutes & hamstrings, calves), search, tap + to build a custom workout,
  start it right away or save it
- Voice coach: a recorded male voice (ElevenLabs "Adam") announces each exercise; works offline
- Summary: time, exercises done and a 3D body map of the muscles you trained
- Editor: add from the library or type in a custom exercise; supersets, muscles, cues
- Backup: export/import your workouts as a JSON file (Settings)

## Run locally

```bash
npm install
npm run dev        # http://localhost:5173 (also on your LAN; see the "Network" URL)
```

`lab.html` (dev only, at `/lab.html`) lets you scrub through every animation.

## Using it on iPhone

Install it: open the site in **Safari → Share → Add to Home Screen**. The home
screen version runs full screen, keeps the screen awake during a workout
(iOS 18.4+), and is exempt from Safari's 7-day storage cleanup. Export a
backup from Settings now and then anyway.

What iOS allows a web app, and how this app works around it:

| iOS limit | What the app does |
|---|---|
| No vibration API | Haptic tick on taps (iOS 17.4–26.4) |
| Web audio can stop your music app | Audio session set to "transient": the voice coach plays over your music and briefly lowers it |
| Silent switch mutes web audio | Everything on screen still works; turn the ringer on to hear the coach |

## Coach voice

The coach lines are pre-recorded clips in `public/voice/`, generated from
`scripts/voice-script.json` (ElevenLabs, voice "Adam", model eleven_multilingual_v2).
The app joins clips like "Next exercise…" + "T-bar row. Three sets of ten."
Exercises without a recording (the newer library exercises and ones added in
the editor) fall back to the phone's built-in voice. To add recordings for new exercises, add lines to the
script, generate them with the same voice, save as `public/voice/<key>.mp3`
(slash → underscore) and regenerate `src/data/voice-clips.js`.

## File structure

```
index.html                 App shell
lab.html                   Dev-only animation lab (not in the build)
vite.config.js             Vite + PWA (manifest, service worker)
public/icons/              App icons (generated by scripts/make-icons.mjs)
src/
  main.js                  Router, action registry, boot
  styles.css               Design tokens (light/dark) and layout
  app/state.js             Shared state + persistence (and the v1 → v2 data migration)
  app/util.js, viewer.js   Formatting helpers, shared 3D viewer
  screens/                 home, plan, library (+ exercise page), workout, summary, editor, settings
  data/exercises.js        The exercise library: groups, cues, mistakes, muscles, demo
  data/workouts.js         Default workouts, built from the library (edits in the app are saved separately)
  data/muscles.js          Muscle names + where each sits on the figure
  lib/session.js           Workout flow: order, supersets, what's next
  lib/coach.js, voice.js   Voice coach (recorded clips, speechSynthesis fallback)
  lib/storage.js           localStorage wrapper (all access try/catch)
  lib/device.js            Wake lock, haptics, iOS audio session
  ui/                      icons, sheets, technique notes + 3D stage
  three/figure.js          Procedural mannequin + two-bone IK
  three/animations.js      One pose function per exercise
  three/props.js           Benches, machines, cables, bars, dumbbells
  three/viewer.js          Scene, camera, orbit controls, render loop
```

## Adding an exercise

Easiest: in the app, open a workout → **Edit** → **Add exercise**, and pick
from the library or choose **Custom exercise**.

To add one to the library in code, add an entry to `src/data/exercises.js`:

```js
{
  id: 'goblet-squat', name: 'Goblet squat', group: 'quads', equipment: 'Dumbbell',
  primary: ['quads', 'glutes'], secondary: ['adductors'],
  cues: ['Chest up', 'Knees out', 'Sit between the heels'],
  avoid: ['Heels lifting', 'Rounding the back at the bottom'],
  animation: 'back-squat',                // any id from three/animations.js
  dose: { sets: 3, reps: '10' },          // default when added to a workout
}
```

New movement patterns need a new entry in `three/animations.js`; `lab.html`
(dev only) shows each demo so you can tune poses.

## Muscle and animation map

Primary muscles glow in the accent colour, secondary ones in a lighter tint.

| Group | Exercises (animation id) |
|---|---|
| Chest | Barbell bench press (`bench-press`), Low-incline DB press (`incline-db-press`), Push-up (`push-up`), Standing cable fly (`cable-fly`) |
| Back | T-bar row (`t-bar-row`), Lat pulldown (`lat-pulldown`), Pull-up (`pull-up`), Single-arm pulldown (`single-arm-pulldown`), Seated cable row (`seated-cable-row`), One-arm DB row ⚑ (`db-row-bench`) |
| Shoulders | Seated DB shoulder press (`overhead-press`), Lateral raise (`lateral-raise`), Seated rear delt fly (`rear-delt-fly-seated`), Face pull ⚑ (`face-pull`) |
| Biceps | Machine curl (`machine-curl`), Preacher curl (`preacher-curl`), Hammer curl (`hammer-curl`) |
| Triceps | Cable pushdown (`triceps-pushdown`), Overhead DB extension (`overhead-triceps`) |
| Core | Knee raises (`hanging-knee-raise` / `captain-knee-raise`), Plank (`plank`), Kneeling cable crunch (`cable-crunch`), Dead bug (`dead-bug`), Pallof press (`pallof-press`) |
| Quads | Barbell back squat (`back-squat`), Lunge, DB in one hand (`lunge-single-db`), Leg press (`leg-press`), Leg extension (`leg-extension`) |
| Glutes & hamstrings | Romanian deadlift (`romanian-deadlift`), Barbell hip thrust (`hip-thrust`), Seated leg curl (`leg-curl`) |
| Calves | Standing calf raise (`calf-raise`) |

⚑ = flagged "Confirm with coach" in the Pull workout.

## Deploy

### GitHub Pages (workflow included)

1. Create an empty repo on GitHub (e.g. `gym-companion`).
2. Push this folder:
   ```bash
   git add -A && git commit -m "Gym Companion v1"
   git branch -M main
   git remote add origin https://github.com/sahar-cohen/gym-companion.git
   git push -u origin main
   ```
3. On GitHub: **Settings → Pages → Source: GitHub Actions**.
4. The workflow builds and publishes to `https://sahar-cohen.github.io/gym-companion/`.

### Vercel

Import the repo at vercel.com/new. It detects Vite (build `npm run build`,
output `dist`). No config needed.

### On your phone

Open the URL, then **Share → Add to Home Screen** (iPhone) or **⋮ → Install app**
(Android). After the first load it works offline.
