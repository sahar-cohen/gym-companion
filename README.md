# Gym Companion

A phone-first workout tracker. Pick a workout, then follow it one exercise at a
time with a looping 3D demo, highlighted muscles, weight/rep logging, and an
automatic rest timer with a voice coach. Spotify controls are built in.
Installable as a PWA and works offline.

## Features

- One exercise at a time: 3D demo (drag/pinch), primary and secondary muscles, form cues
- Log weight and reps per set; "Last time" line; per-exercise progress chart
- Rest timer (auto, ±15 s remembered per exercise), supersets, skip/jump
- Voice coach: a recorded male voice (ElevenLabs "Adam") announces exercises, rest and the last 3 seconds; works offline
- Summary: time, sets, volume, personal bests, and a 3D body map
- Editor: add or edit workouts and exercises, supersets, demo, muscles, playlist
- Spotify: now playing, play/pause/skip, and auto-start a playlist per workout
- Backup: export/import all data as a JSON file (Settings)

## Run locally

```bash
npm install
npm run dev        # http://localhost:5173 (also on your LAN; see the "Network" URL)
```

`lab.html` (dev only, at `/lab.html`) lets you scrub through every animation.

## Using it on iPhone

Install it: open the site in **Safari → Share → Add to Home Screen**. The home
screen version runs full screen, keeps the screen awake during a workout
(iOS 18.4+), and is exempt from Safari's 7-day storage cleanup. Export a
backup from Settings now and then anyway.

What iOS allows a web app, and how this app works around it:

| iOS limit | What the app does |
|---|---|
| Apps in the background are paused, so no alert when rest ends while you're in another app | Music controls live inside the app, so you don't need to leave it. The timer runs off timestamps, so it's correct when you come back ("Rest ended 0:40 ago"). |
| No vibration API | Haptic tick on taps (iOS 17.4–26.4); a full-screen **Go** flash plus sound and voice when rest ends |
| Web audio can stop Spotify | Audio session set to "transient": cues play over your music and briefly lower it |
| Silent switch mutes web sounds | The voice coach and the visual flash still work. Turn the ringer on for the chime. |

## Coach voice

The coach lines are pre-recorded clips in `public/voice/`, generated from
`scripts/voice-script.json` (ElevenLabs, voice "Adam", model eleven_multilingual_v2).
The app joins clips like "Rest. Next up…" + "T-bar row." + "Set two of three."
Exercises without a recording (e.g. ones added in the editor) fall back to the
phone's built-in voice. To add recordings for new exercises, add lines to the
script, generate them with the same voice, save as `public/voice/<key>.mp3`
(slash → underscore) and regenerate `src/data/voice-clips.js`.

## Spotify setup (one time, ~3 minutes)

Spotify requires every app to have its own Client ID. Since February 2026,
development-mode apps need the owner to have **Premium** and allow up to 5 users.
Without Premium you get "now playing" only.

1. Go to <https://developer.spotify.com/dashboard> → **Create app**.
2. Name: `Gym Companion`. APIs: **Web API**. Redirect URI: your app URL exactly,
   e.g. `https://sahar-cohen.github.io/gym-companion/` (for local dev: `http://127.0.0.1:5173/`;
   Spotify rejects `localhost`).
3. Copy the **Client ID**, then either:
   - paste it in the app under **Settings → Spotify → Client ID**, or
   - for GitHub Pages builds, add a repo variable `SPOTIFY_CLIENT_ID`
     (Settings → Secrets and variables → Actions → Variables), or
   - locally, put `VITE_SPOTIFY_CLIENT_ID=...` in `.env.local`.
4. In the app: **Settings → Spotify → Connect**. Pick a playlist per workout in the editor.

Open the Spotify app once before a workout so your phone shows up as a device.

## File structure

```

lab.html                   Dev-only animation lab (not in the build)
vite.config.js             Vite + PWA (manifest, service worker)
public/icons/              App icons (generated by scripts/make-icons.mjs)
src/
  main.js                  Router, action registry, boot
  styles.css               Design tokens (light/dark) and layout
  app/state.js             Shared state + persistence
  app/util.js, viewer.js   Formatting helpers, shared 3D viewer
  screens/                 home, workout, summary, editor, settings
  data/workouts.js         Default workouts (edits made in the app are saved separately)
  data/muscles.js          Muscle names + where each sits on the figure
  lib/session.js           Workout flow: sets, supersets, rest, skipping
  lib/history.js           Logged sets, "last time", progress series, PRs
  lib/voice.js             Voice coach (speechSynthesis)
  lib/spotify.js           Spotify PKCE login + player API
  lib/storage.js           localStorage wrapper (all access try/catch)
  lib/device.js            Wake lock, sound, haptics, iOS audio session
  ui/                      icons, sheets, chart, Spotify mini player
  three/figure.js          Procedural mannequin + two-bone IK
  three/animations.js      One pose function per exercise
  three/props.js           Benches, cables, bars, dumbbells
  three/viewer.js          Scene, camera, orbit controls, render loop
```

## Adding an exercise (e.g. Workout 3)

Easiest: in the app, select the workout → **Edit** (or **Add exercises**).
Or, to change the built-in defaults in code, add an object to `exercises` in `src/data/workouts.js`:

```js
{
  id: 'goblet-squat', name: 'Goblet squat', sets: 3, reps: '10', weight: 20,
  rest: null,            // null = default from settings
  superset: null,        // same string on consecutive exercises = superset
  primary: ['quads', 'glutes'], secondary: ['adductors'],
  cues: ['Chest up', 'Knees out', 'Sit between the heels'],
  animation: 'lunge-single-db',          // any id from three/animations.js
  camera: { az: 60, el: 10, dist: 3.4, y: 0.9 },
}
```

New movement patterns need a new entry in `three/animations.js`.

## Muscle and animation map

| Exercise | Animation | Primary (strong glow) | Secondary (light tint) |
|---|---|---|---|
| Lunge, DB in one hand | `lunge-single-db` (left leg forward, DB in right hand) | quads, glutes | adductors, hamstrings, obliques |
| T-bar row | `t-bar-row` (~50° hinge, landmine pivot behind) | lats, rhomboids, mid traps | rear delts, biceps, spinal erectors |
| Low-incline DB press | `incline-db-press` (~18° bench) | upper chest | front delts, triceps |
| Lateral raise (SS A1) | `lateral-raise` | side delts | upper traps |
| Seated rear delt fly (SS A2) | `rear-delt-fly-seated` (~60° lean) | rear delts | rhomboids, mid traps |
| Machine curl | `machine-curl` (shoulder flexed 90°) | biceps | brachialis, brachioradialis |
| Knee raises | `hanging-knee-raise` / `captain-knee-raise` | lower abs | hip flexors |
| Rear delt pull ⚑ | `face-pull` (rope at face height) | rear delts | rhomboids, mid traps, rotator cuff |
| Single-arm pulldown | `single-arm-pulldown` (right arm) | lats | teres major, biceps, lower traps |
| Seated cable row | `seated-cable-row` | rhomboids, mid traps, lats | rear delts, biceps, spinal erectors |
| Bent-over row on bench ⚑ | `db-row-bench` (one-arm DB row) | lats, rhomboids | rear delts, biceps |
| Preacher curl, one arm | `preacher-curl` (right arm) | biceps (short head) | brachialis |

⚑ = flagged "Confirm with coach" in the app.

## Deploy

### GitHub Pages (workflow included)

1. Create an empty repo on GitHub (e.g. `gym-companion`).
2. Push this folder:
   ```bash
   git add -A && git commit -m "Gym Companion v1"
   git branch -M main
   git remote add origin https://github.com/sahar-cohen/gym-companion.git
   git push -u origin main
   ```
3. On GitHub: **Settings → Pages → Source: GitHub Actions**.
4. The workflow builds and publishes to `https://sahar-cohen.github.io/gym-companion/`.

### Vercel

Import the repo at vercel.com/new. It detects Vite (build `npm run build`,
output `dist`). No config needed.

### On your phone

Open the URL, then **Share → Add to Home Screen** (iPhone) or **⋮ → Install app**
(Android). After the first load it works offline.
